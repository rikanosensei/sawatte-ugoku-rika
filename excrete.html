不要な物質のゆくえ

細胞でできたアンモニアを運んで、体の外に排出されるまでの道すじをたどろう。

尿素にした
0 こ
尿になった
0 こ
体外へ
0 こ

右上の「全身の細胞」で、アンモニアができたよ。アンモニアの粒を指でつまんで、まずどこへ運ぶか考えよう。

見る場所

使い方
  1. 右上の「全身の細胞」にあるアンモニアの粒を指でつまんで、体の中の器官まで運ぶ。どこに運ぶか予想して、その上で指をはなす。
  2. アンモニアが尿素になったら、尿素をまた運ぶ。尿になると、輸尿管を通ってぼうこうにたまる。
  3. 「ぼうこうの尿を体外に出す」を押して、尿を体外に排出する。
  4. 尿素を皮膚の汗腺に運ぶと、汗として排出されるようすも見られる。
  5. 腎臓をタップするか「② 腎臓を大きく見る」を押すと、腎臓で血液から不要な物質がこし出されるようすが見られる。

画面をさわらなくても、「1つ運んでもらう」のボタンで運べます。

このモデルについて

体の図と器官の形・位置は、分かりやすくするために単純にしています。本物では、アンモニアや尿素は血液にとけて運ばれます。ここでは、粒を指で運ぶことで、血液が運ぶ道すじを表しています。

「腎臓を大きく見る」は、こし出すしくみを表したイメージ図で、本物の腎臓のつくりとはちがいます。赤い粒は、血液にふくまれる、こし出されないものを表しています。
